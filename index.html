📐 Modular Architecture & Data Flow

Specification Section 2.2

1. Faculty Initiator

Teacher logs into the portal, selects assigned lecture session, and starts dynamic QR broadcast on the projector display.

2. Student Scanner

Student points device camera at the classroom screen. The client captures the encrypted token along with GPS coordinates.

3. Server Validation

Java backend checks QR expiry, verifies duplicate avoidance for the day, checks GPS radius tolerance, and writes to database.

4. Live Sync & Dashboard

Attendance counter increments in real time on teacher's screen, student receives digital slip receipt, and % updates automatically.
